  • Negation in two's complement: invert every bit and add 1, so −x = x′ + 1. The most negative value has no positive counterpart.
  • Subtraction: A − B = A + B′ + 1, an adder with inverted B and a carry in of 1.
  • Overflow: unsigned addition overflows when the carry out of the top bit is 1. Signed addition overflows when both operands have the same sign and the result has the other; equivalently V = (carry into the top bit) ⊕ (carry out of it).
  • Extension: sign-extend two's complement values by copying the sign bit into the new high bits; zero-extend unsigned values.
  • Shifts: a left shift by k multiplies by 2ᵏ; a logical right shift divides an unsigned value by 2ᵏ, rounding down; an arithmetic right shift divides a signed value by 2ᵏ, rounding toward −∞.
  • Other codes (): BCD stores each decimal digit in 4 bits; excess-B stores u to represent u − B; Gray code g = b ⊕ (b ≫ 1) changes one bit per step; one-hot uses n bits for n values.

Floating-point formats (). Normal values are (−1)ˢ × 1.f × 2e − bias. An exponent field of all zeros encodes ±0 (f = 0) and subnormals (−1)ˢ × 0.f × 21 − bias; all ones encodes ±∞ (f = 0) and NaN (f ≠ 0). Boolean algebra

Each identity has a dual, obtained by swapping AND with OR and 0 with 1 ().

Name | OR form | AND form Identity | X + 0 = X | X · 1 = X Null element | X + 1 = 1 | X · 0 = 0 Idempotency | X + X = X | X · X = X Complement | X + X′ = 1 | X · X′ = 0 Involution | (X′)′ = X | Distributivity | X + Y·Z = (X + Y)·(X + Z) | X·(Y + Z) = X·Y + X·Z Covering | X + X·Y = X | X·(X + Y) = X Combining | X·Y + X·Y′ = X | (X + Y)·(X + Y′) = X Simplification | X + X′·Y = X + Y | X·(X′ + Y) = X·Y Consensus | X·Y + X′·Z + Y·Z = X·Y + X′·Z | (X + Y)(X′ + Z)(Y + Z) = (X + Y)(X′ + Z) De Morgan | (X + Y)′ = X′·Y′ | (X·Y)′ = X′ + Y′
  • XOR: X ⊕ Y = X·Y′ + X′·Y; X ⊕ 0 = X; X ⊕ 1 = X′; X ⊕ X = 0; (X ⊕ Y)′ = X ⊕ Y′ (XNOR). XOR is commutative and associative, and an n-input XOR is 1 when an odd number of its inputs are 1.
  • Shannon expansion: F = X′·F(X = 0) + X·F(X = 1), the basis of building any function from multiplexers ().
  • Complete sets: {NAND}, {NOR}, {AND, NOT}, {OR, NOT}, and the 2-to-1 multiplexer. There are 2^(2ⁿ) distinct functions of n variables.
  • Canonical forms (): F = Σm(minterms where F = 1) = ΠM(maxterms where F = 0). AND-OR logic equals NAND-NAND; OR-AND equals NOR-NOR.
  • K-maps (): rows and columns in Gray-code order (00, 01, 11, 10); a group of 2ᵏ adjacent 1s eliminates k variables; cover every 1 with the fewest, largest groups, starting with essential prime implicants.

Glossary

Every definition from the guide, plus other key terms, in alphabetical order. Each term links to the place where it is explained.

The overall speedup from making a fraction p of a task s times faster: 1/((1 − p) + p/s), which can never exceed 1/(1 − p) however large s becomes. The number of arithmetic operations a program performs per byte it moves to or from main memory. Through the roofline model it decides whether the program is limited by memory bandwidth or by compute. A combinational block that performs the arithmetic or logical operation selected by its control inputs and reports status flags such as zero, negative, carry and overflow. A queue whose write side and read side run on different clocks. Gray-coded pointers cross between the domains through synchronizers so the full and empty flags can be computed safely. Hit time + miss rate × miss penalty, applied level by level through a memory hierarchy. Two or more threads of a warp accessing different words in the same shared-memory bank in one instruction, which forces the hardware to serialize the accesses. A code that stores each decimal digit separately in 4 bits, using the patterns 0000 to 1001. Guessing the outcome of a branch so that a pipeline can keep fetching instructions; a wrong guess flushes the instructions fetched after it and costs a penalty of several cycles. The guarantee that all cores see one consistent order of values for each memory location even though each has a private cache; maintained by protocols such as MESI. The unit of data that a cache stores and transfers, typically 64 bytes, with one tag for the whole line. Also called a block. An adder that computes its carries from generate (g = a·b) and propagate (p = a ⊕ b) signals in a tree, so its delay grows with the logarithm of the width instead of linearly. A signal passing between logic clocked by unrelated clocks. It needs a synchronizer, a handshake or an asynchronous FIFO, depending on what is being passed. Stopping the clock of idle registers to save dynamic power, using an integrated clock-gating cell (a latch and an AND gate) so that no glitches reach the clock. The difference between the arrival times of the same clock edge at two flip-flops. It adds to the margin of one of the setup and hold checks and subtracts from the other. Complementary MOS logic: each gate has a PMOS pull-up network and a dual NMOS pull-down network, so that in steady state one of them is off and almost no current flows. Combining the memory accesses of the 32 threads of a warp into as few wide transactions as possible, which happens when consecutive threads access consecutive addresses. The logic, a decoder or a state machine, that generates the signals steering a datapath through each instruction. The slowest register-to-register path in a design; it sets the minimum clock period. Two threads accessing the same memory location concurrently without synchronization, at least one of them writing. It is undefined behavior in C and C++. The part of a processor that holds and transforms data: registers, the ALU, multiplexers and the connections between them, steered by control signals. (X·Y)′ = X′ + Y′ and (X + Y)′ = X′·Y′: the complement of an AND is the OR of the complements, and the complement of an OR is the AND of the complements. Filtering the rapid transitions a mechanical switch produces when it opens or closes, by accepting a new level only after the input has been stable for several milliseconds. An input combination whose output value does not matter, because it never occurs or its output is ignored. It may be treated as 0 or 1, whichever gives the simpler circuit. Dynamic RAM: one transistor and one capacitor per bit. It is dense and cheap, but reading is destructive and every cell must be refreshed periodically. The fraction of each period that a periodic signal spends high. A PWM signal with duty cycle D averages to D × Vhigh. The power spent charging and discharging capacitance as signals switch, α·C·V²·f. Sampling an input only at a clock transition, as a flip-flop does, rather than throughout a clock level, as a latch does. A representation in which the stored unsigned value u stands for u − B. A fraction represented as an integer with an implied binary point at an agreed position, such as Q8.8; its arithmetic is integer arithmetic plus scaling. An edge-triggered storage element: it captures its D input at the active clock edge and holds it until the next one. Routing a result from a later pipeline stage straight to the ALU inputs of a following instruction, so that it need not wait for the register write. Also called bypassing. Field-programmable gate array: a chip of lookup tables, flip-flops, memory blocks and arithmetic units joined by programmable routing, configured after manufacture to implement a digital design. A circuit that adds three bits A, B and Cin, producing S = A ⊕ B ⊕ Cin and Cout = A·B + Cin·(A ⊕ B). An error-correcting code that adds parity bits over overlapping subsets of the data bits, so the pattern of failed checks locates any single-bit error. A momentary glitch at a combinational output that should stay constant, caused by unequal path delays when one input changes. Adding the consensus term removes it. The minimum time a flip-flop's input must stay stable after the active clock edge. Inter-integrated circuit: a two-wire (SDA, SCL), open-drain bus on which a controller addresses devices by 7-bit address and every byte is acknowledged. The standard floating-point formats and arithmetic rules: sign, biased exponent and fraction with a hidden leading 1, plus zeros, subnormals, infinities and NaNs, with correctly rounded operations. A function the processor runs automatically when an enabled interrupt occurs. It should be short, and variables it shares with the main program must be volatile and accessed atomically. A truth table laid out in Gray-code order so that minterms differing in one variable are adjacent, which makes the largest groupings, and the minimal expression, visible. A level-sensitive storage element: transparent, with the output following the input, while its enable is active, and holding its value while the enable is inactive. A shift register whose input is the XOR of selected bits. With the right taps it cycles through all 2ⁿ − 1 nonzero states, producing pseudo-random sequences. In a steady-state system, the average number of items inside equals the throughput multiplied by the time each spends inside. For memory: data in flight = bandwidth × latency. An instruction that needs the value loaded by the instruction just before it. The value arrives too late for forwarding, which costs one stall cycle in the classic five-stage pipeline. A small memory addressed by a function's inputs that holds the function's truth table; the basic logic element of an FPGA. A state machine whose outputs depend on the current state and the current inputs. A flip-flop state between 0 and 1 that can last for an unbounded time when the input changes inside the setup-and-hold window. The probability that it persists decays exponentially with the time allowed. A state machine whose outputs depend only on the current state. The noise voltage a logic signal can tolerate before it may be misread: NMH = VOH − VIH and NML = VIL − VOL. The Verilog <= assignment: all right-hand sides in a time step are evaluated before any left-hand side changes, which models flip-flops that all sample at the same edge. Twice the highest frequency present in a signal. Sampling more slowly causes aliasing, in which high frequencies appear as false low ones. The number of warps resident on a GPU multiprocessor as a fraction of the maximum, limited by registers, shared memory and block limits. A code of n bits for n values with exactly one bit set; used for state encodings and select signals because decoding it is trivial. An output that can only pull low or let go. A pull-up resistor supplies the high level, so several outputs can share one wire without conflict. Executing instructions as soon as their operands are ready rather than in program order, while a reorder buffer commits the results in order to keep exceptions precise. An extra bit chosen so that the total number of 1s is even (or odd), so that any single-bit error is detected. Dividing an operation into stages separated by registers so that several operations are in progress at once, which raises throughput at a cost in latency and hazards. A circuit that outputs the index of its highest-priority active input, together with a flag saying whether any input is active. A resistor to the supply that sets the level of a line when nothing drives it, used with buttons, open-drain buses and unused inputs.
